可以直接粘贴 AI 生成的 Python 字典模板，系统会自动识别 name、text、variables、formula、 answer_count、answer_units 等字段并填入下方表单。 如果模板里包含 image_filename，图片仍请使用原来的上传框上传原图。

用于学情画像的薄弱知识点分析；不填则根据题名自动归类。
提示：变量占位符请使用 {% raw %}{{变量名}}{% endraw %}（例如 {% raw %}{{F}}{% endraw %}），不要放在 LaTeX 下标里；数学公式用 \( LaTeX公式 \)。旧格式 __F__ 和 {% raw %}{{ problem.var_values.F }}{% endraw %} 会自动转换。
支持格式：PNG, JPG, GIF, SVG。最大16MB。模板中识别到图片文件名时，仍需在这里上传对应原图。
支持两种写法：r,R,i,B 或带范围 v0[0,30],a[0.2,8],t[0.5,20]，系统会自动标准化格式。
使用Python数学表达式，多答案用逗号分隔。例如：i * R / (pi * (r/100)**2)
为每个答案指定单位，用逗号分隔。例如：
- 单答案题目：V
- 三个答案的题目：V,A,Ω
- 无量纲答案用减号：- 或 -,-
与答案数量保持一致。
支持单答案和多答案反推；多答案会识别独立目标并在可行时联立求解，失败时自动回退旧生成规则。
添加说明
变量命名规范：
  • 半径：r, a
  • 电阻：R
  • 电流：i, I
  • 磁场：B, B0
  • 速度：v
  • 长度：l, L
  • 质量：m
  • 角速度：omega
公式编写提示：
  • 使用标准数学函数：pi, sin, cos, sqrt
  • 注意单位转换（cm → m）
  • 多答案用逗号分隔
  • 可以使用 sympy 符号计算
题目内容格式：
  • HTML标签支持
  • LaTeX数学公式
  • 图片路径：/problem_image/图片名.png
答案单位格式：
  • 单位用逗号分隔
  • 无量纲答案用 "-" 表示
  • 单位数量必须与答案数量一致
  • 示例：V,A,Ω 或 -,- 或 V,-
图片使用说明
图片规范：
  • 建议尺寸：400×300 像素
  • 格式：PNG（推荐）、JPG、GIF、SVG
  • 文件命名：使用英文和数字，避免中文
  • 图片将自动插入到题目内容开头
